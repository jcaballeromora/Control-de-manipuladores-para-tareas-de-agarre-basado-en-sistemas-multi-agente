# 🖥️ Entornos de Simulación (Simscape y RoboDK)

Este directorio está destinado a los entornos de simulación virtual desarrollados para la validación preliminar del esquema de control multi-agente (MARS) y la sintonización del controlador de fuerza por admitancia.

El entorno de simulación consta de:
* Modelos de dinámica multicuerpo desarrollados en **MATLAB / Simscape**.
* Estaciones de trabajo virtuales y cinemática en **RoboDK**.
* Scripts auxiliares para la ejecución de trayectorias y validación de *caging* en simulación.

## 📥 Disponibilidad y Acceso
